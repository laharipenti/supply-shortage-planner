# Data dictionary

_Generated by `python -m ssp docs` from `src/ssp/schema.py` - the same definitions drive the loader, the validator and the SQL DDL, so this document cannot drift from the code._

Conventions: quantities are in the SKU's `base_uom` unless stated; money in USD; dates ISO `YYYY-MM-DD`; weeks are ISO weeks `2026W01`..`2026W52` (week 1 starts Monday 2025-12-29, the planning as-of date). `Req` = required (non-empty). `Unique` = unique across the table.
